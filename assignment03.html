Task 3:Complete a short terminal-navigation practise sheet. # Task 3: Terminal Navigation Practice ## 1. What is a Terminal? A terminal is a tool that allows us to give commands to the computer using text. It helps us navigate folders and manage files. ## 2. Basic Terminal Commands ### Command 1: `pwd` This command shows the current working directory. ### Command 2: `ls` This command lists files and folders in the current directory. ### Command 3: `cd foldername` This command moves into the specified folder. ### Command 4: `cd ..` This command moves one level up to the parent folder. ### Command 5: `mkdir foldername` This command creates a new folder with the given name. ### Command 6: `clear` This command clears the terminal screen. In Windows Command Prompt, we can use `cls`. ## 3.
