Design Choices

Colour Palette: Deep blue gives a professional appearance. Orange is used for buttons and highlights.

Typography: The Segoe UI font provides readable text, with a line-height of 1.6 for comfortable reading.

Layout: The content width is limited to 800px. White sections on a light background improve readability.

Maintainability: CSS variables store the main colours and border radius, making future changes easier.
