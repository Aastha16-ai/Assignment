CSS Box Model

Understanding the four parts of an HTML element

MARGIN — Space Outside the Border

BORDER — Edge Around the Element

PADDING — Space Inside the Border

CONTENT

This is the actual content of the element.

Box Model Explanation

1. Content: The text, image or other information inside an element.

2. Padding: The space between the content and the border.

3. Border: The line surrounding the content and padding.

4. Margin: The space outside the border that separates elements.
